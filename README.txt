Requires Python 3.10+; no packages or API keys needed.

Run these commands from this folder:
  python3 -m unittest -v
  python3 task_tracker.py add "Read module"
  python3 task_tracker.py list
  python3 task_tracker.py complete 1

Tasks are saved to data/tasks.json (excluded from Git).
An optional --data PATH argument BEFORE the command uses another data file.
